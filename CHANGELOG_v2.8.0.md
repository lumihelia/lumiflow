# LumiFlow v2.8.0

## New: DOWNLOAD ZIP — conversation with images and files

A new **DOWNLOAD ZIP** button saves the conversation together with its images and attachments:

```
lumiflow_chatgpt_2026-10-21T09-44-27.zip
├── conversation.md        images appear where they were in the chat
└── media/
    ├── 001-photo.jpg
    └── 002-generated-image.png
```

- **ChatGPT and Claude**: images you uploaded, attached files (PDF, Word, spreadsheets, …) and AI-generated images. Images generated by ChatGPT were never exported before; they now appear between the text they belong to.
- **Claude** files for which only extracted text was kept are saved as `.txt`. When Claude only provides a preview image of a document, it is saved as e.g. `report.pdf (preview).png` rather than mislabelled as a PDF.
- Files that have expired or cannot be downloaded are listed under "Not included" at the end of `conversation.md`.
- The ZIP is built inside the page, so you can close the popup; progress shows at the bottom right of the page.
- Gemini and DeepSeek export text only for now (noted in the file).

## Smaller changes

- TXT / MD exports and API compression mark where an image or file was (`[Image: photo.jpg]`), instead of silently dropping it.
- Text formatting for exports moved to a shared `export.js`, used by the popup, the page script and the background, so every export looks the same.

## Permissions

- New **optional** host permission `https://*.oaiusercontent.com/*`, where ChatGPT stores files. The browser asks for it the first time you use DOWNLOAD ZIP on ChatGPT. It is not required at install, so updating does not trigger a permission prompt or disable the extension.
- Privacy policy (md / zh / txt) updated accordingly.

## Checks

- End-to-end with the unpacked extension on mock ChatGPT and Claude conversations: ZIP integrity verified with Python `zipfile` and `unzip`; every Markdown link resolves to a file in the ZIP; image bytes are identical to the source.
- Full regression (Manual / Auto / API compression / inject / extraction cleanup / DeepSeek): all pass.
- Mozilla `web-ext lint`: 0 errors.
